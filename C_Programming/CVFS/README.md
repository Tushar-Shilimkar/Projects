# CVFS – Custom Virtual File System

**CVFS (Custom Virtual File System)** is a memory-based virtual file system developed in **C Programming** to understand the internal working of file systems and Operating System concepts.

The project simulates important file-system components such as **Inodes, Super Block, File Table, UAREA, UFDT, File Descriptors and Data Buffers**.

## 🚀 Features

* Create and delete files
* Read and write file data
* File permission management
* File information using `stat`
* List files using `ls`
* Manual/help commands
* File Descriptor management
* Error handling
* Dynamic memory allocation
* Inode-based file management

## 🖥️ Supported Commands

```text
help
man
creat
ls
ls -a
write
read
stat
unlink
clear
exit
```

## 🛠️ Technologies

* **Language:** C
* **Concepts:** Operating Systems, File Systems, Inodes, Pointers, Linked Lists, Dynamic Memory Allocation
* **Interface:** Command Line

## ▶️ Run the Project

```bash
gcc CVFS.c -o myexe
./myexe
```

## 🎯 Purpose

This project is developed for educational purposes to gain practical understanding of **File System Internals and Operating System concepts using C**.
